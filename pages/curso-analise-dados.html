Análise de Dados

O curso de Data Analytics prepara profissionais para transformar grandes volumes de dados em informações úteis para a tomada de decisões. Ao longo da formação, os alunos aprendem a coletar, organizar, analisar e interpretar dados, utilizando ferramentas como Excel, SQL, Python e Power BI para identificar padrões, acompanhar indicadores e criar relatórios visuais.

Com foco em aplicações reais e resolução de problemas empresariais, o curso é indicado tanto para quem deseja iniciar uma carreira na área de tecnologia quanto para profissionais que buscam migrar de setores como administração, marketing, vendas e finanças para o universo dos dados.

1º semestre

  1. Introdução à análise de dados.
  2. Excel e Google Sheets.
  3. Matemática e estatística básica.
  4. Organização, limpeza e interpretação de dados.

2º semestre

  1. Consultas a bancos de dados com SQL.
  2. Lógica de programação com Python
  3. Manipulação de dados com Pandas.
  4. Análise exploratória e identificação de padrões.

3º semestre

  1. Power BI e construção de dashboards.
  2. Gráficos e comunicação visual de dados.
  3. Indicadores de desempenho (KPIs).
  4. Análise de resultados e métricas de negócio.

4º semestre

  1. Análises completas com dados reais.
  2. Estatística aplicada à tomada de decisões.
  3. Elaboração de relatórios e apresentações.
  4. Portfólio, currículo e preparação para entrevistas.

5º semestre

  1. Estatística aplicada e análise preditiva.
  2. Introdução ao aprendizado de máquina (Machine Learning).
  3. Automação de relatórios e processos com Python.
  4. Modelagem de dados e consultas SQL avançadas.

6º semestre

  1. Indicadores estratégicos e tomada de decisão.
  2. Projeto de análise com dados reais.
  3. Storytelling com dados e apresentação de resultados.
  4. Portfólio, estudos de caso e preparação para entrevistas.
